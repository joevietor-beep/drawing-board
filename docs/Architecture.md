# Drawing Board Architecture

## Primary Rooms

- **Sanctuary**: Morning Meditation, Journal, Constitution.
- **Board Room**: Today's Focus, DealDocs, Prospect Radar, Analytics, Projects.
- **Studio**: Article Architect, Social Vibe, Image Roll, Video Edits, Plan Notes.

## Broad-Strokes Workflow

1. Create the Tauri shell with theme and navigation.
2. Present the three primary rooms.
3. Reveal tools when a room is selected.
4. Implement focused placeholder pages.
5. Connect real functionality one tool at a time, beginning with Article Architect.

The initial application includes a progressive meditation flow and a locally
saved Article Architect draft. External services are connected later, one tool
at a time.
