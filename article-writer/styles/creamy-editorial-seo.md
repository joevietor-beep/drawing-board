# Creamy.Digital SEO Style Guide

## Goal

SEO should improve discoverability without harming readability.

Write for people first.

Optimize for search engines second.

---

## Headlines

Use descriptive headlines.

Prefer 3–5 words.

Occasionally use 6 words when necessary.

Headlines should naturally contain important keywords.

Never use generic labels such as:

- Hook
- Reframe
- Solution
- Outcome
- CTA
- Introduction
- Conclusion

Each heading should preview the section that follows.

---

## Keywords

Choose one primary keyword.

Choose three to five supporting keywords.

Use keywords naturally.

Never force repetition.

---

## Meta Description

Write one compelling summary between 140–160 characters.

Focus on usefulness.

Avoid clickbait.

---

## URL Slug

Generate a concise, readable slug.

Use lowercase.

Separate words with hyphens.

Avoid unnecessary filler words.

---

## Images

Every image requires:

### Filename

Use descriptive keywords.

Example:

short-form-video-med-spa.png

---

### Alt Text

Describe the scene naturally.

Include the primary keyword when appropriate.

Avoid keyword stuffing.

---

### Title

Use a readable title matching the image's purpose.

---

### Description

Write one sentence explaining the image and its relationship to the article.

---

## Internal Linking

Suggest two opportunities to link to related articles when appropriate.

---

## Excerpt

Generate a one or two sentence excerpt that encourages readers to continue reading.

---

## Readability

Prefer:

- Short paragraphs
- Clear headings
- Logical flow
- Simple language
- Active voice

---

## Final SEO Checklist

Every article should include:

✓ SEO title

✓ Focus keyword

✓ Supporting keywords

✓ Meta description

✓ SEO slug

✓ Optimized headings

✓ Optimized image metadata

✓ WordPress excerpt

✓ Internal linking suggestions

The reader should never notice the SEO.

It should simply feel like an exceptionally well-written article.

---

## No SEO Theater

Never sacrifice readability for SEO.

Never repeat keywords unnaturally.

Never create headings solely because a search engine may prefer them.

The article should read naturally to a human being first.

Excellent writing is the best SEO strategy.
